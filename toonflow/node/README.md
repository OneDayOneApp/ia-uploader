# 永久存档

把画布上的图片、视频或音频上传到 [Internet Archive](https://archive.org)，获得永久、公开、可引用的存档地址。

## 输入与输出

| 端口 | 方向 | 类型 | 说明 |
| --- | --- | --- | --- |
| 素材 | 输入 | IMAGE / VIDEO / AUDIO | 一个端口同时接收图片、视频、音频，只接受一条连线 |
| 存档地址 | 输出 | STRING | 上传成功后的 archive.org 详情页链接 |

把「图片」「视频」「音频」这类节点的输出连到本节点的**素材**端口即可。
没有连接上游时，也可以直接在节点里选择本地文件上传。

节点会按素材类型自动切换预览方式：图片显示缩略图、视频显示播放器、音频显示波形播放条，
并自动推断 archive.org 的 `mediatype`（`image` / `movies` / `audio`）。

## 使用方法

1. 第一次使用时点「密钥」，填入 archive.org 的 Access Key 与 Secret Key。
   密钥只保存在**当前浏览器**的本地存储里，不会上传到服务器。
   在 <https://archive.org/account/s3.php> 生成。
2. 把图片或视频节点连到本节点，或直接点「选择文件」。
3. **上传前**在节点里填写归档信息（都会写进 archive.org 的元数据）：

   | 字段 | 对应的 archive.org 元数据 |
   | --- | --- |
   | 标题 | `title`，留空取文件名 |
   | 条目 ID | 条目地址里的标识，留空自动生成 |
   | 描述 | `description` |
   | 作者 | `creator` |
   | 标签 | `subject`，逗号分隔 |
   | 合集 | `collection`，默认 `opensource_media` |

   作者、标签、合集收在「更多信息」里，点开才显示。

4. 点节点上的「**归档到 archive.org**」按钮，等待进度条走完。
5. 归档成功后会直接展示返回的两个链接：
   - **详情页** `https://archive.org/details/<条目ID>`
   - **直链** `https://archive.org/download/<条目ID>/<文件名>`

   点「复制」可以一键复制详情页地址。

## 注意

- **上传即公开**。archive.org 的条目默认公开可检索，请勿上传隐私内容。
- 上传成功不代表立即可见 —— archive.org 是异步处理的，条目和缩略图通常需要 1–5 分钟才完整出现。期间打开详情页可能显示为空。
- 同一个条目 ID 再次上传会叠加文件，不会覆盖历史版本。
- 上传走浏览器直连 archive.org，大文件会占用较多内存。

## 归档记录会一直保留

填写的标题、条目 ID、描述、作者、标签、合集，以及归档成功后的链接，
都存在节点自己的数据里（`node.data.archive`），随画布一起保存。

- 退出项目、刷新页面、重开浏览器 —— 归档成功的链接都还在
- 复制节点时归档信息一并复制
- 只有把上游素材换成**另一个文件**时，才会清空上一次的结果

## 不允许重复归档

一旦归档成功，节点会记录下：

- 条目 ID、标题、描述、作者、标签、合集
- **详情页链接**与**直链**
- **归档时间**

此后按钮变成「已归档 · 不可重复归档」，再点会直接提示：

> 该素材已经归档过，不能重复归档。如需重新归档，请点结果卡片里的「重新归档」，或更换上游素材。

这样做是为了避免在 archive.org 上留下多份重复条目。

### 两种重新归档的方式

| 方式 | 效果 |
| --- | --- |
| 换一个上游素材（连线到别的文件） | 自动清空本次记录，按钮恢复可用 |
| 点结果卡片里的「重新归档」 | 只清空本节点的记录，archive.org 上的旧条目**不受影响** |

## 文件名规则

上传到 archive.org 的文件名按这个顺序决定：

1. **标题** —— 填了就用作文件名（自动补扩展名）
2. **上游原始文件名** —— 上游节点给的名字有意义时直接沿用
3. **兜底** —— 上游是 `475641ea-…-bd1bb2b4270a.mp4` 这种 UUID 时，
   生成 `chequ-20261102231500.mp4`（带时间戳，能区分批次）

文件名会去掉路径分隔符和 `: * ? " < > |` 等保留字符，保留中文与空格。
